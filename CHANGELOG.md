# Changelog

All notable Apelles Android changes are documented here.

## v0.6.0-apelles-android

- Added native Android app support with `arm64-v8a` and `x86_64` builds.
- Added Android Storage Access Framework integration for opening, placing, saving, and exporting files.
- Added offline-first autosave and crash recovery.
- Added Arabic text shaping and right-to-left paragraph support.
- Added imported `TTF`, `OTF`, and `TTC` font support.
- Added mobile UI scaling, immersive system-bar handling, and touch-oriented controls.
- Added PSD/project compatibility and layered editing workflows.
- Added Android-focused README documentation and release packaging.

## Development

The Android build is a pre-release testing build. Report device-specific problems through the
[Android compatibility issue template](.github/ISSUE_TEMPLATE/android-compatibility.yml).
