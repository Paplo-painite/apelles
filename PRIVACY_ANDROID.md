# Apelles Android Privacy Notice

## العربية

Apelles Android يعمل محليًا وبنظام **offline-first**. لا يطلب التطبيق صلاحية `INTERNET` في Manifest، ولا يرفع الصور أو ملفات المشاريع إلى خادم.

- الصور وملفات PSD وPCraft تُعالج محليًا على الجهاز.
- الحفظ التلقائي والاستعادة تُخزّن داخل مساحة التطبيق الخاصة.
- الخطوط التي يستوردها المستخدم تُخزّن داخل مساحة التطبيق الخاصة.
- عند استخدام Android Storage Access Framework، يختار المستخدم الملف أو الوجهة بنفسه، ويُستخدم URI الذي منحه النظام لإتمام العملية.
- قد تتوفر ملفات مؤقتة قصيرة العمر أثناء الاستيراد أو التصدير أو الحافظة، ويجري تنظيفها تلقائيًا.
- لا يجمع التطبيق تحليلات استخدام أو معرّفات إعلانية في هذه النسخة.

إذا أضيفت خدمات سحابية مستقبلًا، يجب تحديث هذه السياسة وطلب موافقة المستخدم قبل نقل أي محتوى.

## English

Apelles Android is a local, **offline-first** editor. The Manifest does not request the `INTERNET` permission, and the application does not upload images or project files to a server.

- Images, PSD files, and PCraft projects are processed locally.
- Recovery data is stored in the app-private storage area.
- Imported fonts are stored in the app-private storage area.
- When Android Storage Access Framework is used, the user selects the file or destination and Android grants the URI access needed for that operation.
- Short-lived temporary files may be created during import, export, or clipboard operations and are cleaned up automatically.
- This build does not collect usage analytics or advertising identifiers.

If cloud services are added later, this notice must be updated and user consent must be obtained before transferring content.
