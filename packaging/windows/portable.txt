Apelles portable mode

While this file sits next to apelles.exe, Apelles keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the ApellesData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Apelles with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Apelles) instead.
If ApellesData can't be written (for example on a read-only drive), Apelles says so and
uses %APPDATA%\Apelles instead.
